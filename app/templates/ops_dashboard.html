How to use this panel

  • Apply Candidate Config requires typing apply in its confirm field.
  • Run Learning Cycle Now requires typing run in its confirm field.
  • Run LLM Review Now force-runs periodic LLM review immediately.
  • LLM Periodic Review cadence controls slow-path external review only, not per-candle decisions.
  • /analyze hot path is local-first now, so runtime decisions no longer depend on external LLM per candle.
  • Spread/ATR Max Ratio tunes how strict the local engine is about spread versus volatility. Higher values allow more setups through.

Detailed guide: see OPS_UI_USAGE_GUIDE.md in the repo.
